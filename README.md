# GO project for simple implementation of TOTP, enveloping encryption and Access token system
This project provides a description of implementation of a web application that replaces email based multifactor authentication system written using Node.js with a custom solution written in Go using Gin while adding additional cryptographic features in form of time based one-time passwords and envelope encryption, as well as providing an example implementation of access refresh token pair. This project illustrates the improvements that can be done on the given system and showcases the commonly utilized security practices in web development.
## Installation
* Follow the installation procedures for Go programming language on the [Go website](https://go.dev/doc/install)
* Run `go get` in the root directory install all dependencies


## Running
Fully utilising the project requires a mobile phone with a camera and application like [Google authenticator](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2&hl=en_NZ&pli=1)
* Run `go run .`

### Available paths
Postman is recommended for browsing the REST API paths
* /register - POST - to register a new user with mfa still disabled. Expects a POST request with body in format of 
```json
{
    "email" : "example@example.com",
    "password" : "12345678"
}
```
* /login - POST - to login a new user, expects body in the same format as `register`
* /login/mfa  - POST - finalize the login if mfa is enabled passing in the structure containing either auth or recovery code 
```json
{
    "code" : "514376",
    "recovery" : ""
}
```
* /mfa/enroll - POST - begin enrollment in mfa, has no body


* /mfa/enroll/qr - GET - get QR code for the use in app like google authenticator
* /mfa/enroll/confirm - POST - get the recovery codes by confirming the authenticator app being connected
```json
{
    "code" : "055307"
}
```


## Notes
A copy of `.env` was provided for example, however key can be generated by going into the `tools` folder and running `go run genkey,go`
